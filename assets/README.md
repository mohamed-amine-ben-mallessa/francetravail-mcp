# Assets

## `demo.gif` — how to record it

The README references `assets/demo.gif`: a short screen recording of **Claude Code**
using this MCP (e.g. running `/francetravail:jobs developer in Paris` and showing the
results table). To create it:

1. Install the plugin in Claude Code (see the main README) so the `francetravail` tools are live.
2. Run a clean, photogenic query — e.g. *"Find web developer jobs in Lyon and the contract breakdown."*
3. Record the terminal with a GIF tool:
   - **macOS/Windows/Linux:** [`asciinema`](https://asciinema.org) + [`agg`](https://github.com/asciinema/agg) (asciicast → GIF), or
   - [`vhs`](https://github.com/charmbracelet/vhs) (script a terminal demo to GIF), or
   - any screen-to-GIF recorder (ScreenToGif, Kap, Peek).
4. Keep it **under ~8 seconds** and **≤ 5 MB** so it loads fast on GitHub.
5. Save it here as `demo.gif`.

Until the GIF exists, GitHub shows a broken-image placeholder — that's expected; replace it
with the recording when ready.
